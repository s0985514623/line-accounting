# category 句型模型

## 實體概述

- **性質**: Aggregate（Category，含子實體 CategoryKeyword）
- **攜帶狀態**: 帳本、收支、名稱、其他分類（is_fallback）
- **Invariant 清單**: 同帳本同收支名稱唯一；每個帳本 × 收支恰有一個「其他」且不可刪；刪除分類時紀錄改歸「其他」、關鍵字刪除

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 查詢分類列表 | Query（LIFF） | 帳本、收支 | id、帳本、收支、名稱、其他分類 | UNAUTHENTICATED / FORBIDDEN / INVALID_ARGUMENT |
| 新增分類 | Creation（LIFF） | 帳本、收支、名稱 | 帳本、收支、名稱、其他分類 | UNAUTHENTICATED / FORBIDDEN / INVALID_ARGUMENT / DUPLICATE_NAME |
| 刪除分類 | Mutation（LIFF） | id | 分類、記帳紀錄、分類關鍵字 | UNAUTHENTICATED / FORBIDDEN / NOT_FOUND / FALLBACK_CATEGORY_UNDELETABLE |

## 測試分析

### 查詢分類列表
**等價類劃分**: 身分合法/非法；缺帳本/缺收支。
**邊界值分析**: 不適用。
**狀態轉移**: 不適用（Query）。
**組合覆蓋**: 帳本 × 收支過濾（混合資料中只取個人支出）。
**錯誤推測**: 「其他」排序位置。

### 新增分類
**等價類劃分**: 必填缺漏各 1；空白名稱；重複名稱；跨帳本/跨收支同名。
**邊界值分析**: 名稱全空白。
**狀態轉移**: 分類 +1。
**組合覆蓋**: 同名 × 不同帳本、不同收支。
**錯誤推測**: 與「其他」或既有分類同名。

### 刪除分類
**等價類劃分**: 一般分類 / 其他分類 / 不存在。
**邊界值分析**: 不適用。
**狀態轉移**: 分類刪除 → 紀錄改歸其他、關鍵字刪除。
**組合覆蓋**: 同時有紀錄與關鍵字。
**錯誤推測**: 其他分類被刪導致無處歸類。
