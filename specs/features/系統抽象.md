# 系統抽象

Boundary：`web-backend`（erm.dbml 存在）。LINE Messaging API 視為外部 Gateway：測試以 stub 接收 reply 內容並驗證。

## 實體清單

| 實體 | 性質 | 攜帶狀態摘要 | 對應 features subfolder |
|------|------|-------------|------------------------|
| 白名單 | 設定（環境變數） | LINE_OWNER_USER_ID | access/ |
| 分類 Category | Aggregate | ledger、entry_type、name、is_fallback、keywords | category/ |
| 分類關鍵字 CategoryKeyword | Category 子實體 | keyword | transaction/（學習）、category/（連帶刪除） |
| 記帳紀錄 Transaction | Aggregate | ledger、entry_type、item、amount、category、occurred_on、note、source | transaction/ |
| 分類按鈕 token PostbackToken | Aggregate（技術性） | token、transaction_id | transaction/ |
| 月度報表 MonthlyReport | Read Model | 收入合計、支出合計、結餘、支出分類佔比 | report/ |
| LINE 回覆 LineReply | Gateway | reply 文字、Quick Reply 按鈕、確認按鈕 | access/ transaction/ report/ |

| 操作 | 所屬實體 | 行為分類 | 輸入參數 | 回傳型別 |

| 加入好友（follow） | 分類 | Creation | LINE userId | LINE 回覆 |

| 確認刪除記帳紀錄（postback） | 記帳紀錄 | Mutation | transactionId、確定/取消 | LINE 回覆 |
| 以表單記帳 | 記帳紀錄 | Creation | 帳本、收支、項目、金額、分類、日期、備註 | Transaction |
| 編輯記帳紀錄 | 記帳紀錄 | Mutation | id + 全欄位 | Transaction |
| 刪除記帳紀錄 | 記帳紀錄 | Mutation | id | 無 |
| 查詢記帳紀錄列表 | 記帳紀錄 | Query | 月份、帳本 | Transaction[] |

## 行為分類與句型骨架

### Creation / Mutation（LINE 入口）
- When：`When "<userId>" 傳送文字訊息 "<text>"`、`When "<userId>" 點擊 postback "<data>"`、`When "<userId>" 加入好友`
- Then（回應）：`Then 回覆訊息應為 "<text>"` / `Then 回覆訊息應包含：`（Data Table）
- Then（狀態）：`Then 記帳紀錄應為：`、`Then 分類應為：`

### Creation / Mutation / Query（LIFF API 入口）
- When：`When 記帳者以 LIFF <操作>：`（Data Table）
- Then（成敗）：`Then 操作成功` / `Then 操作失敗，violation_type 為 "<violation>"`
- Then（資料）：`Then 查詢結果應為：`（Data Table）

## 共用契約

### Postcondition 模式
- LINE 記帳成功：建立 1 筆 transaction + 回覆「已記帳」摘要（帳本、收支、項目、金額、分類、日期）+「刪除」postback 按鈕。
- LIFF 成功：HTTP 2xx + 回傳資源。

### Violation 模式
| 前置條件 | LINE 入口 | LIFF 入口 |
|---------|----------|----------|
| LINE webhook 簽章不正確 | HTTP 401，不處理任何事件 | — |
| LIFF ID token 無效 | — | 401 `UNAUTHENTICATED` |
| 非白名單 userId | 回覆「此服務不開放使用」，不寫入任何資料（postback 則不回覆） | 403 `FORBIDDEN` |
| 參數缺少/格式錯 | 回覆格式說明或具體錯誤 | 400 `INVALID_ARGUMENT` |
| 資源不存在 | 回覆「此紀錄已不存在」 | 404 `NOT_FOUND` |
| 分類與帳本/收支不符 | — | 400 `CATEGORY_MISMATCH` |
| 分類名稱重複 | — | 409 `DUPLICATE_NAME` |
| 刪除「其他」分類 | — | 422 `FALLBACK_CATEGORY_UNDELETABLE` |

### 共用文字
- 格式說明：`格式：[公 ][日期 ][+]項目 金額[ 備註]，例如：午餐 120、昨天 午餐 120、公 11/10 +顧問費 30000 A客戶；多筆請分行輸入`
- 非白名單：`此服務不開放使用`

## 共用句型

跨 2+ domain 共用（Phase 2.5 萃取）：

| # | 句型 | Handler | 使用 domain |
|---|------|---------|------------|
| G1 | `Given 白名單 LINE userId 為 "<userId>"` | aggregate-given（設定） | access、transaction、category、report |
| G2 | `Given 今天為 "<YYYY-MM-DD>"` | aggregate-given（時鐘） | transaction、report |
| G3 | `Given 系統中有以下分類：` | aggregate-given | access、transaction、category、report |
| G4 | `Given 系統中有以下記帳紀錄：` | aggregate-given | transaction、category、report |
| W1 | `When "<userId>" 傳送文字訊息 "<text>"` | command（webhook） | transaction、report |
| T1 | `Then 回覆訊息應為 "<text>"` | readmodel-then（LINE Gateway stub） | access、transaction、report |
| T2 | `Then 操作成功` | success-failure | transaction、category |
| T3 | `Then 操作失敗，violation_type 為 "<violation>"` | success-failure | transaction、category、report |
| T4 | `Then 記帳紀錄應為：` | aggregate-then | transaction、category |
| T5 | `Then 分類應為：` | aggregate-then | access、category |

Data Table 欄位統一：`id | 帳本 | 收支 | 項目 | 金額 | 分類 | 日期 | 備註 | 來源`（帳本值：個人/公司；收支值：支出/收入；來源值：LINE文字/LIFF表單）。分類 Data Table：`id | 帳本 | 收支 | 名稱 | 其他分類`。

## 變異點索引

| 實體 | 特有行為 | 需要的專屬句型類別 |
|------|---------|------------------|
| 分類 | 首次加好友 seed、刪除時改歸「其他」 | When 加入好友、Then 分類應為 |
| 分類關鍵字 | 選擇分類後自動學習 | Given/Then 分類關鍵字 |
| 記帳紀錄 | 文字解析、Quick Reply、刪除確認 | When postback、Then 回覆含按鈕 |
| 月度報表 | 文字摘要與 JSON 兩種呈現 | Then 摘要 Data Table |
