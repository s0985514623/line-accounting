# report 句型模型

## 實體概述

- **性質**: Read Model（MonthlyReport，由 transactions 彙總）
- **攜帶狀態**: 帳本、月份、收入合計、支出合計、結餘、支出分類佔比（分類、金額、佔比）
- **Invariant 清單**: 結餘 = 收入合計 − 支出合計；佔比四捨五入至小數一位；分類依金額由大到小；月份以 Asia/Taipei 計

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 查詢月度文字摘要 | Query（webhook message） | （文字在句型中） | 摘要（帳本、月份、收入合計、支出合計、結餘）；佔比（分類、金額、佔比）；圖表連結（月份、帳本） | 非白名單 → 不開放 |
| 查詢月度統計圖表 | Query（LIFF） | 月份、帳本（皆可省略） | 同上（無連結） | UNAUTHENTICATED / FORBIDDEN / INVALID_ARGUMENT |

## 測試分析

### 查詢月度文字摘要
**等價類劃分**: 四種指令（本月/上月 × 個人/公司）；有支出/無支出。
**邊界值分析**: 10-31 與 11-01 的月份邊界；一月查上月（跨年）；佔比 66.7/33.3 四捨五入。
**狀態轉移**: 不適用（Query）。
**組合覆蓋**: 帳本 × 月份 4 組。
**錯誤推測**: 負結餘（只有支出的月份）。

### 查詢月度統計圖表
**等價類劃分**: 身分合法/非法；月份格式錯（2026-13、202611）；帳本非法值。
**邊界值分析**: 月份邊界同上。
**狀態轉移**: 不適用。
**組合覆蓋**: 有參數 / 無參數（預設本月個人）。
**錯誤推測**: 無資料月份的空佔比。
