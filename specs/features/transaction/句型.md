# transaction 句型模型

## 實體概述

- **性質**: Aggregate（Transaction）+ 子實體（CategoryKeyword 學習）+ 技術 Aggregate（PostbackToken）
- **攜帶狀態**: 帳本、收支、項目、金額、分類、日期、備註、來源
- **Invariant 清單**: 金額 > 0 且為整數；分類必須與帳本、收支一致；同一 postback token 只建立一筆紀錄

## 測試分析

### 以文字訊息記帳
**等價類劃分**: 前綴組合（無／公／+／公 +）各 1；備註有無；分類名稱命中／關鍵字命中／未命中。
**邊界值分析**: 金額 0、負數、小數。
**狀態轉移**: 未命中 → 不記帳、跳分類按鈕。
**組合覆蓋**: 「公 +營業收入 30000 A客戶」同時覆蓋兩個前綴與備註。
**錯誤推測**: 關鍵字跨收支誤用（支出關鍵字用在收入）；只打項目或只打數字。

### 選擇分類完成記帳
**等價類劃分**: 一般分類 / 其他分類 / 不符分類 / 不存在分類。
**邊界值分析**: 不適用。
**狀態轉移**: token 未使用 → 已使用。
**組合覆蓋**: 不適用。
**錯誤推測**: 重複點擊同一按鈕。

### 請求刪除 / 確認刪除記帳紀錄
**等價類劃分**: 存在 / 不存在；確定 / 取消。
**邊界值分析**: 不適用。
**狀態轉移**: 存在 → 已刪除；取消維持。
**組合覆蓋**: 不適用。
**錯誤推測**: 重複確認已刪除紀錄。

### 以表單記帳 / 編輯記帳紀錄
**等價類劃分**: 每個必填欄位缺漏各 1；分類不符（收支不符、帳本不符）、不存在。
**邊界值分析**: 金額 1（最小合法）、0、-1、12.5；日期 2026-13-01、2026-02-30。
**狀態轉移**: 編輯後來源維持不變。
**組合覆蓋**: 編輯同時改帳本與分類。
**錯誤推測**: 改帳本卻沿用舊分類。

### 刪除記帳紀錄 / 查詢記帳紀錄列表
**等價類劃分**: 身分合法/非法；月份有紀錄/無紀錄；個人/公司。
**邊界值分析**: 10-31 的紀錄不出現在 11 月；月份 2026-13。
**狀態轉移**: 刪除後紀錄消失。
**組合覆蓋**: 月份 × 帳本。
**錯誤推測**: 同日多筆的排序。
