# Clarify Session 2026-11-12 12:04

## Idea

我要做一個 LINE 記帳的應用，目標是可以在 LINE 上面輸入個人/公司的支出與收入，並有統計功能。最後會部署在 Linode VPS 上面，本機透過 git 部署流程更新，幫我進行規劃。

## Q&A

- Q: 誰會使用？ → A: 只有我自己（單一使用者）
- Q: LINE 上的輸入方式？ → A: 打字快速記帳 + LIFF 表單兩者都要
- Q: 個人/公司帳本如何區分？ → A: 預設記個人，訊息前綴「公」記公司
- Q: 統計在哪裡看？ → A: LINE 文字摘要 + LIFF 圖表網頁
- Q: 統計維度？ → A: 每月收入/支出/結餘 + 分類佔比
- Q: 分類處理？ → A: 系統預設分類，使用者可增刪
- Q: git 部署路線？ → A: GitHub + GitHub Actions 部署到 VPS
- Q: VPS 執行方式？ → A: 加入 VPS 既有共用 Docker Compose 基礎設施（共用 Caddy reverse proxy、共用 PostgreSQL server 但獨立 database/user、網路隔離），共三套應用；本應用不自帶 Caddy/Postgres
- Q: 網域/HTTPS？ → A: 有網域，由（共用）Caddy 自動憑證
- Q: 技術棧？ → A: Node.js + TypeScript + PostgreSQL + Prisma
- Q: Flow Tree v1 大方向？ → A: confirm
- Q: 打字記帳時分類判斷？ → A: 第一個詞對得到分類（名稱/關鍵字）就直接記；對不到才跳 Quick Reply 按鈕讓使用者選
- Q: 收入怎麼輸入？ → A: 開頭加「+」為收入（如「+薪水 50000」），沒加為支出
- Q: 記錯怎麼辦？ → A: 記帳成功回覆附「刪除」按鈕；LIFF 列表可編輯/刪除
- Q: 日期？ → A: 打字記帳預設今天；要改日期到 LIFF 改
- Q: 文字摘要觸發？ → A: 打「本月」「上月」或點 Rich Menu 按鈕皆可
- Q: 幣別？ → A: 只有台幣（TWD）
- Q: 收據照片？ → A: MVP 不做
- Q: 備份？ → A: 共用基礎設施已統一備份，本應用不另做
- Q: 非本人加好友？ → A: 只允許設定的 LINE userId（白名單）；其他人回覆「不開放」
- Q: 個人/公司分類？ → A: 各自一套分類
- Q: 文字記帳格式？ → A: 「[公 ][+]項目 金額[ 備註]」，金額後的文字為備註
- Q: 項目如何對應分類？ → A: 自動學習——比對分類名稱或已學習關鍵字；以按鈕選分類後記住該項目詞，下次自動歸類
- Q: 預設分類？ → A: 個人支出（餐飲/交通/購物/居住/娛樂/醫療/其他）、個人收入（薪資/獎金/其他）、公司支出（進貨/薪資/租金/水電/交通/文具/其他）、公司收入（營業收入/其他）
- Q: 金額？ → A: 只允許正整數（TWD）
- Q: 無法解析的訊息？ → A: 回覆簡短格式說明
- Q: 刪除按鈕行為？ → A: 先跳「確定刪除？」確認按鈕，確認後才刪除
- Q: 刪除有紀錄的分類？ → A: 允許刪除，舊紀錄改歸該帳本同收支類型的「其他」
- Q: 文字摘要兩本帳？ → A: 預設只看個人；「公 本月」/「公 上月」看公司
- Q: 分類佔比？ → A: 支出分類全列（金額+百分比，由大到小），收入只列合計
- Q: LIFF 列表？ → A: 依月份 + 帳本篩選，日期新到舊
- Q: AI 預設（時區 Asia/Taipei、LIFF 全欄位可編輯、圖表預設本月個人、分類按鈕草稿放 postback data + 唯一 id 防重複） → A: 全部接受
